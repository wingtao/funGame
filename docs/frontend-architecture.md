# 首批作品 · 纯前端技术基线

日期：2026-11-05；状态：首版已落地，具体运行说明见各作品 README。适用于 [买车测评](../apps/car-fit/docs/technical-design.md) 与 [今日已赚](../apps/daily-earnings/docs/technical-design.md)。产品规则见各作品 PRD，视觉规则见 [公共设计规范](design-style.md) 及作品风格文档。

## 1. 技术决策

| 事项           | 首版选择                                     | 原因与边界                                                     |
| -------------- | -------------------------------------------- | -------------------------------------------------------------- |
| 工程           | pnpm workspace、React、TypeScript、Vite      | 沿用现有模板与锁文件，各作品独立包和 dist                      |
| UI             | Tailwind 4、shadcn / Radix、Lucide、原创 SVG | 复用交互基础，按项目主题定制，不引入游戏引擎                   |
| 页面与业务状态 | React useReducer / useState                  | 数据量小；不引入全局状态库和服务端缓存库                       |
| 表单           | React Hook Form + Zod + @hookform/resolvers  | 字段校验、跨字段约束、脏值和草稿管理；依赖在实施时锁定兼容版本 |
| 持久化         | localStorage + Zod 校验                      | 仅存用户配置，访问、解析和写入全部捕获异常                     |
| 分享           | Canvas 2D → PNG Blob → 下载 / Web Share      | 专用脱敏数据模型，不截取整个 DOM、不上传图片                   |
| 动画           | CSS transform / opacity                      | 状态驱动，遵循低动效设置；首版无需 Motion                      |
| 测试           | Vitest、Testing Library、Playwright          | 重点覆盖计算、用户流程、隐私与网络边界                         |
| 页面导航       | 受控视图状态，必要时 hash                    | 不把用户数据放 URL，不依赖服务端路由回退                       |
| 部署           | 静态托管                                     | 分别构建发布，无 API、SSR、数据库和运行时密钥                  |

不新增 Turborepo、公共 UI 或公共业务包。先在各项目内实现，出现真实复用后再提取。测试依赖按实际运行位置声明，业务依赖不得只依赖根目录偶然存在的包。

## 2. 分层与数据流

```text
输入 / 浏览器事件
  → 表单解析与校验
  → 应用 reducer：更新有效配置或草稿
  → 纯业务函数：派生计算与状态
  → React 视图 / 角色状态 / 分享专用模型

持久化适配器 ↔ 已验证的配置与草稿
```

- `domain/` 不导入 React、DOM 或 localStorage；函数显式接收输入，计算结果可复现。
- `features/` 组织用户流程，`components/` 负责展示，`platform/` 处理浏览器能力。
- 暂未通过校验的输入保持为字符串，不能用 `Number('')` 把空值误判为 0。
- 需要解析的外部值都作为 unknown；禁止使用 any、非空断言或类型断言替代校验。
- 已验证的金额用整数分存储；中间计算允许高精度小数分，展示时取整。使用 Intl.NumberFormat 统一币种和位数。
- 派生结果不作为主要持久化数据，防止规则变更后继续显示旧计算。

## 3. 存储与错误处理

每份存储使用 `{ schemaVersion, updatedAt, payload }`；买车测评另存规则版本。updatedAt 仅帮助同步判断，不作为可信审计时间。使用各自 PRD 指定的键。

1. 首次渲染前同步读取和校验，不通过网络获取数据。
2. 无记录 → 初始界面；合法记录 → 恢复；损坏 / 不支持版本 → 可恢复提示，不静默覆盖原始数据。
3. 读取失败或配额不足 → 内存继续工作，持续显示未保存状态，不阻塞计算。
4. 文本草稿防抖约 300ms 写入；提交、步骤切换和主动保存立即尝试写入。不能仅依赖关闭页面时保存。
5. 重置只删除本作品键，禁止 localStorage.clear()；损坏记录由用户确认后清除。
6. 同步事件不回写相同记录，避免标签页循环广播。买车测评遇到其他标签页更新时提示重新载入，避免覆盖正在编辑的方案；今日已赚按其方案自动更新有效配置。

## 4. 本机图片生成

采用固定 750×1000 逻辑像素的竖版画布，输出最高 1500×2000 像素 PNG。系统字体、原创本地角色 SVG / 图片和自动换行文本由显式渲染函数绘制。

- UI 先构造 ShareModel 白名单，只包含允许公开的字段；绘图函数不接收完整 Store 或 PRD 输入对象。
- 导出视图与网页展示独立，避免隐藏 DOM 中残留敏感字段；以 React 文本和 Canvas 文本绘制用户名称，禁止拼接 innerHTML。
- 角色资源随首屏必要资产预载。导出前等待解码，失败可使用同样不含敏感信息的文字版卡片；禁止加载跨域图片导致污染画布。
- 先生成 Blob 并展示预览。用户点击分享时同步调用支持文件的 Web Share；不支持时下载，用户主动取消分享不当作失败弹错。
- 预生成文件避免异步渲染耗尽浏览器的用户激活窗口。Blob URL 在预览替换、关闭或组件卸载时释放，下载完成前不提前释放。
- 下载受限时保留图片预览并说明长按保存，不访问远程截图接口。

## 5. 工程与发布

每个应用提供 dev / build / preview / typecheck / test / test:e2e；继承工作区 TS 与 ESLint，构建先通过类型检查。测试专用 globals / tsconfig 限定在测试目录，不能放宽业务规则。

文档已占用正式项目目录，不能直接运行同名 `pnpm new`。初始化时生成临时项目，仅合入模板应用文件，保留 docs 和 README，修改正式包名后删除临时目录、更新锁文件。

两个站点各自使用独立站点地址优先；需要子路径部署时显式配置 Vite base，实际托管环境验收资源路径。对应用 JS 和公共资产使用构建哈希，HTML 不设置不可更新的长期缓存。没有 Service Worker，不承诺断网后冷启动。

默认不做运行时业务 fetch、不用 CDN 字体、分析脚本、远程日志或外部素材。静态服务器仍会接收常规资源请求，站点不得把薪资、存款等拼到请求路径或查询参数。HTTPS 用于原生分享等浏览器能力；HTTP 下保留下载降级。

## 6. 验证门槛与实施顺序

1. 初始化各应用与检查命令，确认文档不丢失。
2. 优先完成纯计算函数、schema 与边界用例。
3. 完成有效数据 / 草稿管理和存储降级。
4. 按作品风格制作基础视觉、原创角色与核心页面。
5. 补充对比、分享、日历、目标等完整 P0 功能。
6. 静态预览运行端到端测试：资源加载后断网，操作与导出仍可完成；检查没有业务 API 和敏感数据出站。
7. 在 320 / 390 / 768 / 1440px、键盘、200% 文字放大、减少动画与隐私模式下验收。
