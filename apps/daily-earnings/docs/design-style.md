## 4. 今日已赚：温暖二维打工小剧场

### 4.1 定位与色板

一位原创小动物在工位陪用户度过工作日，工资数字是主角。场景适合长期挂着，偶尔出现轻松的生活反馈。

| 语义       | 建议色值  | 用途                                 |
| ---------- | --------- | ------------------------------------ |
| 页面背景   | `#FAF6EF` | 暖白底色                             |
| 卡片表面   | `#FFFFFF` | 设置与数字区域                       |
| 主要文字   | `#332F2A` | 正文、标题                           |
| 次要文字   | `#71675D` | 状态和辅助信息                       |
| 主要收入色 | `#28654E` | 收入数字、进度和确认操作             |
| 场景浅绿   | `#DCE8D5` | 植物、背景区域                       |
| 暖橙       | `#E9B878` | 灯光、目标与道具                     |
| 边界色     | `#D8CEC1` | 非关键分隔；必要控件边界需另验对比度 |

卡片使用轻阴影与细边框，建议阴影为 `0 6px 20px rgb(51 47 42 / 6%)`。相较买车测评减少粗描边与硬阴影。

### 4.2 角色与场景

- 默认提案为一只圆润、略带困意但友善的原创水豚上班族；首版名称为“阿豚”，造型见 Workroom 组件。
- 角色动作克制，避免持续兴奋的营业感。幽默通过眼神、小动作和少量道具表达。
- 固定工位场景包含桌椅、电脑、杯子、植物和窗户，保持统一视角与光源。
- 首版提供上班前、工作中、午休、下班后、休息日五种状态；可共用底图，通过角色姿态与道具切换。
- 角色或场景区域固定尺寸比例，状态切换不改变主数字的位置。
- 首版不混入像素风或写实角色；无需完整房间经营和装扮系统。

### 4.3 页面要求

| 区域     | 必须呈现                       | 优先级                       |
| -------- | ------------------------------ | ---------------------------- |
| 今日收入 | 币种、累计金额、“估算”说明     | 第一视觉焦点                 |
| 当前状态 | 工作 / 午休 / 下班等、计薪状态 | 与收入就近展示               |
| 工作进度 | 时间进度、下班倒计时           | 第二层级                     |
| 陪伴场景 | 小动物及对应工作状态           | 建立氛围，不能挤压金额       |
| 小目标   | 目标名称、金额与完成状态       | 一屏突出当前目标，其他可展开 |
| 工具操作 | 设置、隐藏金额、全屏           | 容易找到，降低视觉权重       |

- 桌面端主内容建议最大宽度 1120px，可采用场景与数字双栏；移动端按收入、状态、进度、场景、目标排列。
- 首次设置按“薪资 → 工作安排 → 趣味目标”分组；示例值必须标识，不能伪装成用户数据。
- 金额增长采用轻量数值过渡；主数字不反复缩放、不每秒弹跳，倒计时不频繁变色。
- “隐藏金额”同时遮蔽页面内的薪资、收入、目标敏感金额和可能泄露它们的工具提示；场景与时间进度继续可用。
- 分享预览中应独立控制是否展示今日金额，默认不带月薪等设置数据。
- 空目标显示可选引导；存储失败给出可理解的提示，不能谎称保存成功。
- 计算规则和计薪时段变化时，要能解释金额变化，不能为动画连续性展示错误数值。

### 4.4 状态与幽默文案

| 状态     | 角色表现           | 文案示例                                                            |
| -------- | ------------------ | ------------------------------------------------------------------- |
| 上班前   | 放下包、整理杯子   | “人还没开机，先喝口水。”                                            |
| 工作中   | 敲键盘、偶尔伸懒腰 | “今天的饭钱，正在路上。”                                            |
| 午休     | 吃饭或靠椅休息     | 计薪时：“吃饭中，计数继续。” 不计薪时：“午休暂停计薪，先好好吃饭。” |
| 目标达成 | 举杯或拿出饭盒     | “午饭自由达成！”                                                    |
| 下班后   | 合上电脑、拿起包   | “今日收工，钱包辛苦了。”                                            |
| 休息日   | 看书、晒太阳       | “今天轮到生活上班。”                                                |

文案必须与实际计薪规则一致。首版不做工资排名、攀比或带有羞辱性质的收入评价。

## 与产品方案对应的视觉细化

- 正式名称为“今日已赚”；首屏就近标注“到手估算”或“税前估算”，不暗示实际到账。
- 首版采用原创水豚工位场景，角色设定已通过原创 SVG 落地；不使用像素或三维风格资产混搭。
- “工作日进度”包含午休，与计薪金额进度不同；不得共用一个没有说明的百分比。
- 午休提供相同休息场景的两种文字状态，明确是否继续计薪。
- 新增工作时区与当月工作日历编辑，控件放入设置，不挤入主页核心区域；手动分母差异用就近说明解释。
- 演示模式有常驻标识，虚拟金额不能与真实设置混淆；进入演示不覆盖正式数据。
- 隐私模式用固定宽度占位符替代敏感金额，避免数字闪现；编辑设置前增加展示确认。
- 目标展示注明“相当于”，达成反馈最多约一秒，后台恢复与重算只更新静态完成状态。
- 增加零工作日、时间配置错误、存储失败、全屏降级及重置确认状态。
- 交付至少包含：首次设置、工作中、两种午休状态、上班前、下班后、休息日、隐私、目标完成和分享预览；桌面双栏与移动纵向稿均需覆盖。

## H5 与文案精简要求

- 以功能标题和必要说明为主，减少标语、英文装饰、角色旁白与重复引导；保留可爱插画。
- 手机端单列展示核心内容，首屏优先题目或收入；表单在窄屏下重新排布，输入字号至少 16px，按钮触控区域至少 44px。
- 使用 viewport-fit=cover 与安全区留白，不限制用户缩放；弹窗限制在动态视口内，打开时锁定背景滚动，关闭按钮可见。
- 分享提供本机图片预览和下载；浏览器限制下载时提示长按图片保存。全屏不可用时保留页面内专注模式。
- 以现代手机浏览器为目标；触屏模拟覆盖问答、输入、弹窗滚动、隐私与分享，微信等内置浏览器的原生分享能力以宿主支持为准。
