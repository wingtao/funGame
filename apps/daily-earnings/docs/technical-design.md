## 1. 架构与依赖

使用 React + TypeScript + Vite、React Hook Form + Zod、Tailwind / Radix。时间计算明确使用 `@js-temporal/polyfill`，通过显式导入使用 Temporal，不假设浏览器原生支持。IANA 时区依赖浏览器提供的 Intl / 时区能力，不查询远程服务；若运行环境不支持所选时区，给出配置错误而不是静默回退。

主场景使用原创 SVG 分层与 CSS 动画，不用 Phaser、Canvas 游戏循环或远程角色服务。Canvas 仅负责分享导出。

```text
src/
  app/                 App、配置 reducer、隐私初始化
  domain/
    schemas.ts         设置 / 目标 / 存储校验
    calendar.ts        工作日覆盖、月份分母、下一工作日
    intervals.ts       时区解析、班次和午休交集
    earnings.ts        纯收入计算与进度
    work-state.ts      PRD 状态优先级

  features/

    sharing/           白名单、预览与导出

```

## 2. 状态与数据模型

- Config：两种薪资输入、当前模式、到手 / 税前口径、IANA 时区、周工作日、班次、可选午休、各日期覆盖与各月份分母覆盖。
- Goals：最多五项，稳定 ID、名称、整数分金额；同额时以 ID 保持稳定排序。
- DaySnapshot：工作日期、当前工作状态、计薪秒数、经过计薪秒数、未舍入收入、工作日进度、倒计时、目标完成集合；每次由 Config 和当前时刻派生，不写成历史流水。
- Runtime：设置面板草稿、演示状态、低动效 / 动画暂停状态、最近 tick、当前庆祝队列；演示不写入正式 Config 和目标记录。
- Persistence：schemaVersion、updatedAt、revision、配置、隐私偏好、当天庆祝日期及 ID。revision 用于标签页更新与测试，不能作为可信服务端版本。

有效配置与设置草稿分开。点击保存完成跨字段校验后原子替换配置、重算并尝试持久化；取消不改变当前计薪。不存逐秒累计金额。

## 3. 时间与计薪引擎

### 3.1 显式时钟和区间

业务入口 `calculateDay(config, nowEpochMs)` 不调用 Date.now 或读取浏览器环境。生产 clock 适配器提供当前时间，测试注入固定时间。

1. 用 nowEpochMs 和设置时区确定 PlainDate 与年月键。
2. 判定日期覆盖和周工作日，得出当日是否工作；按 PRD 决定状态优先级。
3. 将班次、午休的本地日期时间转换为 ZonedDateTime，使用 disambiguation: reject，捕获不存在 / 歧义时间；对午休边界同样校验。
4. 使用实际时间戳构造半开区间，扣除非计薪午休。校验日内合法、无重叠、总计薪时间 >0。
5. 已计薪时长是计薪区间与当天截至当前时刻区间的交集和，始终限制到 [0,H]。
6. 按 PRD 用月薪 / 时薪公式计算收入。只有月薪需要 N；N=0 返回可展示的错误或休息状态，不执行除法。
7. 工作日进度另外按含午休的整段班次计算，不复用计薪进度。

月薪和目标存整数分，金额计算用有限 Number 中间值；约束内数值保持可用精度，禁止逐秒叠加和提前舍入。目标越界判断优先用“已过计薪毫秒×薪资分”与“目标分×分母”比较；超出安全整数范围的乘积使用 BigInt，避免展示舍入提前触发目标。向 UI 返回数值结果及明确单位，不暴露 BigInt 给 JSON 存储。

月工作日统计按本地日历日期枚举，不能用固定 24 小时跳过日期。下一有效班次最多查找未来 366 天；可跳过无法解析的日期并说明配置问题，全部不可用时返回错误状态。

### 3.2 调度与重算

- 可见页面约每秒采样一次真实时刻；挂载、visibilitychange、pageshow、focus、配置和 storage 事件立即重算。
- 不可见时停止装饰循环与常规 tick；恢复后一次重算，不回放遗漏秒数。
- StrictMode 下 effect 可安全挂载和清理，不重复创建计时器、监听器或庆祝。
- 每次 tick 检测工作日期 / 月份是否变化；跨日重建当天目标记录，跨月重新计算默认分母。
- 稳定配置下按“日期 + 配置修订号”缓存班次、N 和下一班次，避免每秒重复枚举日历；时区或设置变更使缓存失效。
- 系统时钟回退按新时间计算，不用 performance.now 伪造只增不减的收入；performance.now 仅辅助识别异常 tick 间隔。

## 4. 目标庆祝与跨标签页

每次重算带原因：自然 tick、首次载入、恢复前台、配置变化、外部更新、时钟跳变。只有可见且时间连续、配置和日期不变的自然 tick 允许触发庆祝。

满足“上次收入 <目标≤本次收入”，且日期相同、ID 未庆祝时加入队列；多项合并一次。恢复、重算、较长 tick 间隔、跨日或时钟跳变只更新完成状态。使用明确连续窗口（初始建议不超过 5 秒）判定正常 tick，便于测试。

当天同一目标修改金额后保留 ID，不重复庆祝；新建目标在创建时按当前收入建立基线。记录仅保留当前工作日期，刷新恢复后不补播。收到 storage 更新时校验记录，更新配置并重算，不回写相同数据。正在编辑设置时提示有外部变化，保存前要求重新载入或明确覆盖，避免静默丢失草稿。

多标签页只在当前可见且有焦点的页面播放庆祝；支持 Web Locks 时对目标记录执行互斥更新。不支持时以本机记录和 storage 通知尽量去重：极端同时操作不提供跨标签严格一次保证，但不能导致错误计薪或反复弹窗。

## 5. 隐私、场景与导出

- 隐私偏好在根组件首次渲染前惰性读取；无法读取时默认遮蔽，等待用户主动展示。加载和错误页不输出敏感金额。
- 数字隐藏时，DOM 可访问名称、title、目标提示与导出模型都不能残留真实值，不能仅用模糊 CSS 隐藏。
- 设置敏感字段默认不挂载，用户确认展示后才渲染；关闭面板销毁草稿中的展示状态，不解除主页隐私。
- ShareModel 默认只有场景、日期、工作日进度和通用文案；仅显式勾选才加入今日金额，类型中从不提供月薪 / 时薪。
- 场景根据 work-state 切换 SVG 分组，收入文本保持独立 HTML，保证可读与可访问性。设置或工作状态变化不移动金额区。
- 支持 reduced-motion 和手动暂停装饰，不影响真实收入；Fullscreen API 失败进入 CSS 专注模式，退出入口始终可见。

## 6. 测试矩阵

| 类别       | 必测内容                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------- |
| 收入       | PRD 两种模式算例，零工作日，金额舍入、目标不提前达成                                      |
| 时段       | 上班 / 午休 / 下班精确边界，计薪与非计薪午休，非法跨夜和全段非计薪                        |

| 时区       | Asia/Shanghai 普通日期；America/New_York 夏令时跳过与重复时刻；设备时区变化不改变工作时区 |
| 调度       | 休眠恢复、后台、跨日跨月、时钟回退、StrictMode 清理                                       |
| 目标       | 自然跨过、首次打开、配置重算、多个同额目标、外部更新和重复刷新                            |
| 隐私与平台 | 首次渲染无闪现、DOM 无敏感提示、分享白名单、全屏失败、存储失败与多标签页                  |

Vitest 使用固定时刻和注入时钟，避免依赖机器当前日期；Playwright 固定时间和时区，覆盖设置 → 工作 → 午休 → 下班、隐私与分享。网络边界测试在首屏资产和时间工具加载后禁用网络，再修改设置、重算和生成图片。
