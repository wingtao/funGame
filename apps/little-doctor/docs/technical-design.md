# 身体探险队 · 技术方案

日期：2026-11-05。纯前端 React + TypeScript + Vite，Zod 校验存储，CSS 与原创 SVG 实现扫描和角色动画。不使用摄像头、上传、后端、游戏引擎或远程业务接口。

## 模块

- `src/domain/game.ts`：八部位与任务数据、辨识联合事件、游戏 reducer、每日奖励去重。
- `src/components/Explorer.tsx`：原创队员与故事精灵，部位高亮与扫描光带。
- `src/platform/storage.ts`：捕获 localStorage 读写异常，按 schema 校验未知数据。
- `src/App.tsx`：页面编排、可见时扫描计时、本机合成提示音、家长设置和贴纸册。

状态：ready → scanning → mission → practice → reviewing → award。确认与任务未全部完成时不能复查；扫描中不能更换部位；取消立即重置当前流程。React effect 清理计时器，后台不累计扫描时间；StrictMode 下不重复计时。

数据键 `fungame:little-doctor:v1`：schemaVersion、sound 和 date/part 贴纸记录。日期来自本机，每个部位每日最多一次；不存儿童姓名、影像、健康数据或未完成扫描。刷新回到准备阶段，已获得贴纸保留。清除只影响本作品。

中文语音默认开启，在点击开始扫描等用户操作后调用浏览器 Speech Synthesis。只选择标记为 localService 的中文音色，不选择远程语音，避免上传家长提醒；没有本地中文音色时明确提示安装系统语音，并保留文字和重播按钮。轻提示音单独设置，默认关闭，使用 AudioContext 本机合成。不请求麦克风或调用网络语音。导入或篡改本机记录不做防作弊认证，因为没有兑现奖励或排行榜。

## 验证

Vitest 检查状态转换、防越级复查、重复点击、奖励去重和 schema。Playwright 在 PC 与触屏模拟下检查部位选择、取消、完整任务、复查、奖励恢复、清除、损坏存储、低动效和断网游玩。构建产物可独立部署。

## 家长习惯场景配置

在家长设置中，按部位选择习惯场景；肚子提供零食、甜饮料、尝试食物与如厕主题，牙齿提供甜食与刷牙主题，眼睛提供屏幕休息与揉眼主题。所有部位也可选择通用任务或自定义家长提醒。

可填写想约定少吃的零食（最多 40 字）和家长提醒（最多 80 字）。孩子端按家长选定场景显示故事角色、三项任务与约定；不将零食名称自动转换成疾病、寄生虫或视力问题的原因。孩子端文案明确故事角色不是检测结果。

配置以部位为键保存在原 v1 存储的 scenarios 字段；旧记录缺少该字段时默认空配置，保留已有贴纸。任务进行中配置只读，完成或取消后可改，避免任务列表中途变化。清除本机数据同时清除配置。

## 中文播报

`domain/narration.ts` 生成开始、过程、结果、任务与复查奖励文本，结果包含家长选择的习惯场景、零食约定和提醒。`platform/speech.ts` 管理本地中文音色、异步 voiceschanged、播放队列和中断。阶段变化替换旧播报，取消、关闭语音、切后台和打开弹窗时停止；可随时点击重播。语音偏好保存于原 v1 存储，旧记录默认开启。

语音是设备能力，不保证所有手机内置浏览器自带中文音色。上线测试验证浏览器调用、文本与中断逻辑；实际声音音质与能否发声需在目标设备检查。自动化使用模拟语音引擎，不把模拟通过当作听感测试。
