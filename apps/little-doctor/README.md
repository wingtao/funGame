# 身体探险队

亲子模拟扫描与好习惯小游戏，支持 PC 双栏和手机 H5 单列布局。八个部位、故事小精灵、习惯任务、复查动画与贴纸收集均在前端完成。

```sh
pnpm install
pnpm --filter little-doctor dev
pnpm --filter little-doctor test
pnpm --filter little-doctor build
```

开发端口 `5175`；`dist/` 可独立静态托管，无环境变量和业务 API。根目录 `pnpm dev` 同时启动所有作品。浏览器测试使用独立预览端口 `4175`：先构建三个应用，再运行 `pnpm test:e2e`。

仅扫描原创卡通队员，不调用摄像头、麦克风或定位。动画、小精灵和奖励均为故事互动，不进行健康检测或诊断。贴纸只记录任务参与，不是健康报告。家长可查看说明、开启本机合成的轻提示音或清除记录。

数据存于 `fungame:little-doctor:v1`，不采集姓名、照片、症状等信息；每部位每天一张贴纸，最多保留最近 90 个有记录的日期。存储损坏或失败时提示并退化为当前会话。加载站点资源后可断网游玩，不承诺离线冷启动。

家长可在右上角设置中按部位配置习惯场景、零食约定和自定义提醒，扫描后对应显示故事与任务。配置只存本机，旧版贴纸记录可继续使用。

中文语音覆盖开始扫描、扫描过程、场景结果、习惯任务和复查奖励；默认开启，点击游戏按钮后播放，可关闭或重播。仅用设备本地中文音色；若设备未安装或浏览器不支持，页面会提示，需安装系统中文语音或改用系统浏览器。语音自动化测试使用模拟引擎验证调用，不代表已完成真机听感测试。
